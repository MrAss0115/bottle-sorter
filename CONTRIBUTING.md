# Contributing

Anyone can read or download this public project. Upstream write and merge access stays with the repository owner, MrAss0115. Do not request write access merely to view the files.

1. Fork the repository into your own account.
2. Create a focused branch, for example `feature/tray-sensor`.
3. Make one related change, explain its purpose, and record checks actually performed.
4. Open a pull request to this repository. The owner reviews and merges accepted changes.

For control changes, describe hardware revision, motor/driver settings, pins, units, and whether validation was code review, host simulation, compilation, or physical testing. Do not describe a pulse counter as measured position.

For CAD changes, edit the F3D source, include updated previews, and state which STEP/STL exports were regenerated. Do not resolve CAD binary conflicts by arbitrarily choosing a file.

Keep credentials in ignored local files. Do not commit student IDs, individual weekly reports, device logs, build outputs, or unrelated personal files. CODEOWNERS requests an owner review when supported; it does not itself enforce access restrictions.
